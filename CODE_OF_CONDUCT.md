# Code of Conduct

We want Tashev Relay to be a useful and welcoming open-source project.

Be respectful, constructive and specific. Critique code and ideas, not people. Harassment, threats, discriminatory abuse, doxxing and spam are not acceptable.

Maintainers may edit or remove content and restrict participation when necessary to protect contributors and the project.

For sensitive conduct concerns, contact the maintainer privately through the GitHub account listed in the repository rather than posting personal information publicly.
